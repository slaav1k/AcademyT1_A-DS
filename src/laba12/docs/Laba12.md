# Практическое задание 12

**Условие**

В рамках второго вебинара, посвященного объектно-ориентированному программированию, разбирались поведенческие шаблоны
ООП. Используя полученные знания, необходимо решить задачу, используя поведение как объект. Хотя примеры кода и
эталонное решение написаны на Java, приём по превращению поведения в объект может быть найден и в других языках
программирования.

К заданию приложен код базового решения на Java и описание к требованиям его изменения. В случае применения других
языков программирования код необходимо будет адаптировать.

**Задание**

Допустим, имеется база данных, хранящая набор записей в виде строк. Необходимо инкапсулировать эти строки и предоставить
возможность запрашивать их, с указанием индекса записи в базе и типа данных, объект которого необходимо получить в
результате. 

Запрос нулевого элемента валиден как со строкой, так и с числом, так как фактически все объекты хранятся в виде строк.
При этом такая строка на самом деле может быть и числом, которое конвертируется в него при вызове метода get. Запрос
строки с индексом 1 возвращает объект типа Point, который конвертируется из хранящейся в первом индексе строки.

База данных должна поддерживать конвертирование строк в любой мыслимый объект.

**ПО для выполнения задания и как развернуть окружение**

Выполнять задание можно в любой IDE.

**Формат результата**

Решение должно быть представлено в форме исходного кода, включающего следующие элементы:

* реализованный код для класса Db и всю его инфраструктуру;
* тестовое окружение с примером реализации Db трёх любых типов;
* тестовые методы, демонстрирующие работоспособность предложенного решения.
