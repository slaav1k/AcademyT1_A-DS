# Практическое задание 10

**Условие**

В рамках второго вебинара, посвященного парадигмам программирования, разбирались вопросы реализации функционального
подхода к программированию. Задание представляет собой требование написать решение по обработке списка значений в
функциональном стиле. В языке Java это делается через StreamAPI. При применении других языков следует внимательно
отнестись к критериям соответствия кода функциональной парадигме. Явное выделение циклов и условий, как правило,
является признаком процедурного подхода и не будет принято.

**Задание**

Дан текстовый файл со строками, где каждая строка содержит имя человека и его номер. Среди этих строк:

* возможны повторения;
* возможны два разных имени под одним номером;
* возможно наличие людей без номера.

Необходимо обработать данные этого файла в функциональном стиле таким образом, чтобы соблюдались следующие условия:

* люди без номера не попадают в итоги;
* все имена должны быть записаны в нижнем регистре с первой буквой в верхнем регистре;
* результатом будут списки людей, сгруппированные по их номеру.

Если это применимо, то выполните автоматическую параллелизацию получения результата.

**Пример**

Входные данные:
вася 5
Петя 3
АНЯ 5
Тото

Выходные данные:
[5:[Вася, Аня], 3:[Петя]]

**ПО для выполнения задания и как развернуть окружение**

Выполнять задание можно в любой IDE.

**Формат результата**

Решение должно быть представлено в форме исходного кода, включающего реализованный код метода и тесты демонстрации его
работоспособности.
