# Практическое задание 7

**Условие**

В рамках материала по динамическому программированию необходимо практически реализовать алгоритм поиска наибольшей общей
подпоследовательности двух строк, который был разобран в теории на вебинаре. Для решения может быть использован любой
язык программирования, в котором есть возможность представлять строку как объект с возможностью доступа к отдельным
буквам, либо же можно использовать вместо строки чистый массив букв. Решение принимается только в том случае, если оно
выполнено методом динамического программирования.

**Задание**

Реализуйте функцию, принимающую на вход две строки, и возвращающую массив строк. Результирующий массив перечисляет все
подпоследовательности максимально возможного размера, которые могут быть построены на основе исходных строк.

Пример:

Входные данные:

Строка 1: ABDEFADRFG

Строка 2: DAFERG

Выходные данные:

[DAFG, AFRG, AERG, DFRG, DERG, DARG]

**ПО для выполнения задания и как развернуть окружение**

Выполнять задание можно в любой IDE.

**Формат результата**

Решение должно быть представлено в форме исходного кода, включающего реализованный метод и тесты демонстрации его
работоспособности.
